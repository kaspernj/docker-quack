Allow callers to cancel in-flight Docker requests with an `AbortSignal`. Every high-level command that already accepts a per-request `timeoutMs` (the root `ping`, `version`, and `info` commands as well as containers, images, networks, volumes, and image tagging) now also accepts an optional `signal` that is forwarded through `DockerConnection` to SnapReq for both buffered and streaming requests. The signal is threaded through multi-step operations (exec create/start/inspect, commit-then-tag, and the tag existing-target replacement path) and is never serialized into a request body.
